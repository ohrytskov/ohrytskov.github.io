# corpgossip.com Internal Dashboard | Next.js + Firebase

## Description

Built an internal operations dashboard for the Sales Gossip platform to help the team manage users and review incoming product feedback from a single interface. The portal includes a lightweight internal landing page, a user administration workspace, and a feedback review screen connected to Firebase Realtime Database.

## Full Description

corpgossip.com (Sales Gossip) Internal Dashboard.

### Project overview

This project is the internal admin portal that supports the main Sales Gossip platform. It gives operators a focused interface for user administration and feedback review without exposing those workflows in the public-facing product.

### What the dashboard includes

- Internal landing page that routes staff into admin and feedback areas
- User administration screen with account inspection and activity-oriented sorting
- Role management controls
- Ban and unban account actions
- Password reset and email reset workflows
- Feedback review page that streams recent product feedback from Firebase
- Route and URL metadata display to make issue triage easier for the internal team

### Stack

- Next.js 13
- React 18
- Firebase Auth
- Firebase Realtime Database
- Tailwind CSS
- Jest for test coverage
