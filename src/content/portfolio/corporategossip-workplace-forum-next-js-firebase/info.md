## Full Description

CorporateGossip (Sales Gossip).

### Project overview

CorporateGossip is a workplace forum for corporate gossip, stories, and discussion threads. It combines social-product mechanics with anonymity-oriented posting so users can share experiences, react to posts, comment on threads, and browse conversations by company or topic.

### What the product includes

- Public feed with server-rendered post loading
- Rich post creation with title, body, tags, company selection, and media upload
- Post detail pages with comments and engagement actions
- User signup, login, username selection, and account flows
- Notifications, profile pages, liked posts, settings, and topic browsing
- Admin tooling for user lookup, role changes, ban and unban actions, and account reset flows
- SEO support through metadata, robots rules, and sitemap generation

### Stack

- Next.js 15
- React 19
- Firebase Auth
- Firebase Realtime Database
- Firebase Storage
- Tailwind CSS
- Cloudflare Workers via OpenNext
- Jest and Puppeteer-based test coverage

### Portfolio positioning

Shows full-stack product delivery rather than a static frontend. It demonstrates authenticated user flows, realtime-backed content management, media handling, SEO support, deployment readiness, and admin operations in the same ecosystem.
