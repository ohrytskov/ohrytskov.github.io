# Encrypted Services

## Description

Goal for the project: implementation of PGP encrypted services (email, file sharing, etc.), implemented the encryption on the front-end as opposed to the usual encryption solutions on the backend. It was a totally new and difficult task. I made all the front-end part of the project.

A summary of the project success: we made encrypted email completely, and our main competitor was proton.me famous service only.
